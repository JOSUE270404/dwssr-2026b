# 🖼️ Convención de Iconos para comits
| Icono | Tipo (`commit`) | Descripción | Ejemplo de Uso |
| :---: | :--- | :--- | :--- |
| ✨ | `feat` | Nueva funcionalidad | Agregar autenticación de usuarios |
| 🐛 | `fix` | Corrección de errores (*bugs*) | Arreglar error al enviar el formulario |
| 🎨 | `style` | Estilos y formato de código | Ajustar indentación y espacios en blanco |
| ♻️ | `refactor`|Mejora de estructura sin cambiar lógica | Simplificar lógica de un componente grande |
| ⚡ | `perf` | Optimización de rendimiento | Comprimir imágenes para acelerar la carga |
| 📝 | `docs` | Actualización de documentación | Actualizar las instrucciones en el README |
| 🧪 | `test` | Pruebas unitarias o de integración | Añadir tests para el módulo de login |
| 🔧 | `chore` | Tareas de mantenimiento o dependencias | Actualizar dependencias de npm |
